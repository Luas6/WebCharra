01 ¿Por qué usar movimiento?

Para explicar una relación, señalar un cambio o confirmar una acción. La animación debe ayudar, no distraer.

02 ¿Y si prefiero menos efectos?

Este laboratorio respeta el ajuste de movimiento reducido del dispositivo. También puedes pausar los efectos desde la cabecera.

03 ¿Funciona sin JavaScript?

Este acordeón sí: utiliza los elementos nativos details y summary. El contenido permanece disponible sin scripts.
